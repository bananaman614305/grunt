<p align="center"><strong>Free AI inference, pooled on your machine.</strong></p>

```bash
npx usegrunt
```

usegrunt installs grunt on this machine. It pools free AI quota and serves one local agent.

https://grunt.run. `milo` and `milo-local` remain aliases.

The published 0.6.5 package has a nine-source pool. This branch prepares a held 0.6.6 draft with eleven sources: Freebuff, OpenCode, Kilo, Zro, Token Harbor, Runcrate, APInex, Mistral Vibe Free, LiveKit, Pollinations and BeatAPI. The draft is not published; Freebuff's provider-policy review and supported scope remain unresolved after a relaying-policy refusal. Setup connects Trusty Squire, connects up to three services at once, tests each, then connects your coding tools. Browser verification is queued when a provider needs you. Pi is optional.

In the 0.6.6 draft, one grouped data-sharing approval covers nine providers, including Pollinations and BeatAPI. `usegrunt add <provider>` remains available for supported providers. Runcrate needs a GitHub account at least 30 days old; APInex needs a personal Gmail Google login and daily free check-in. Mistral uses its native Vibe Free coding allowance, not ordinary API credit. NVIDIA stays optional while account verification is unvetted; Cloudflare Qwen is excluded by choice. The draft's default `kilo` source selects `particle-ai/particle-1:free`. Repeat setup preserves previously connected API sources.

LiveKit adds DeepSeek V4.1 Flash through its free Build plan, using one free project and the official CLI's browser login. The documented included inference allowance is $2.50 per calendar month with a hard stop and no card. Keep the account on Build. LiveKit documents [zero data retention and no training for inference](https://docs.livekit.io/agents/models/inference/), so it needs no sharing approval. The route passed short-prompt, tool-call and 210,077-token context checks through Grunt.

The 0.6.6 additions are BeatAPI's continuous free DeepSeek V4.1 Flash route and Pollinations' fixed community GLM 5.3 Flash route. BeatAPI permits one successful request per minute; its separate $2 welcome credit is not spent by the free model. Pollinations requires a key with a numeric zero budget, Quest Pollen Only enabled and minimal usage permissions, plus a positive unused Quest balance. Its one-time first-key reward supplies that balance without being spent by the free route; community availability is best effort. Both need approval for uncertain upstream retention and training. Their production-adapter Grunt prompt, tool/result and over-200K context proofs, independent review and local checks passed; publication remains held.

Within OpenCode, new conversations rotate across DeepSeek V4.1 Flash Free,
GLM 5.3 Flash Free and Big Pickle. Follow-ups keep their model, and quota errors
try another free model. These models may share provider limits; the pool does
not create extra credit balances or purchase credits.

Zro setup confirms the Free plan, no purchased usage balance and no payment method before connecting it. Keep that account free: Zro uses the same model ID on its paid plans, so changing the account outside grunt can change billing. Token Harbor uses its explicit `:free` model ID. Runcrate requires no paid balance, no card and automatic top-ups off; APInex uses only its `free/` route and never spends wallet funds; Mistral Vibe keeps pay-as-you-go off. Setup shows provider-specific data-sharing disclosures together and remembers approved policy versions in a private receipt. Declining or cancelling skips those providers and continues with Zro and LiveKit, subject to their free-account checks. Changed or newly added policies require another grouped approval. Background setup never prompts, and both signup and routing require the current receipt where required.

Kilo Particle 1 is post-trained from DeepSeek V4.1 Flash; it is a distinct model with a listed one-million-token context. Its free route requires no account or API key and supports native function calls. Anonymous access is limited to 200 requests per hour per IP and upstream capacity; it uses no one-time credits. The catalog permits training on prompts, so the changed Kilo disclosure requires fresh grouped approval. Standard DeepSeek routes remain paid; Auto Free is a changing pool and is no longer the default in 0.6.6. The published 0.6.5 package retains its previous Kilo behavior.

API-provider keys stay in Squire. The anonymous Kilo Particle route uses no credential; grunt verifies the exact model and zero reported cost before accepting its answer.
